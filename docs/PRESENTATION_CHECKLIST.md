# Tasterist Presentation Script and Feature Checklist

Use this as a live demo script tomorrow. It is ordered so each section naturally leads into the next.

## 1. Pre-Demo Setup (5 minutes before)

- Open desktop browser at `/login`.
- Open mobile browser (or responsive mode) at `/login`.
- Prepare one staff account and one admin account.
- Ensure there is at least:
  - 1 taster today,
  - 1 future taster,
  - 1 leaver,
  - 1 record with notes.
- Confirm you can access:
  - Dashboard,
  - Today,
  - Month,
  - Stats,
  - Add Taster,
  - Record Leaver,
  - Find Taster,
  - Admin Tasks,
  - Settings,
  - Admin Menu.

## 2. Opening Script (30-60 seconds)

- “Tasterist is our class-management system for day-to-day taster and leaver workflows.”
- “I’ll walk through it as a staff member first, then admin controls, then mobile.”
- “The focus is speed: quick daily actions, clear status, and traceable records.”

## 3. Login and Security Demo

- Sign in as a normal user.
- Explain first-login password gate:
  - New/default-password users are forced to set password before app access.
  - Existing users with set passwords go straight in.
- Show sign-out popover from bottom-left profile (Yes/Cancel).

## 4. Sidebar Walkthrough (Desktop)

- Overview section:
  - Dashboard
  - Today
  - Month
  - Stats
- Actions section:
  - Add Taster
  - Record Leaver
  - Find Taster
  - Admin Tasks
  - Help / Suggestions
- Bottom utilities:
  - Admin Menu (admins only)
  - Settings
- Confirm active-page indicator in sidebar.

## 5. Dashboard Demo

- Show headline cards:
  - Tasters this month,
  - Leavers,
  - Tasters to members,
  - Open follow-ups,
  - Net movement,
  - Weekly bookings.
- Show Today’s Tasters by location (Lockwood/Honley/Preschool).
- Show month mini-calendar and quick navigation cards.
- Show programme bar graph with tasters/leavers color legend.
- Click from dashboard into a relevant page to show drill-down behavior.

## 6. Today / Day View Demo

- Open Today and switch location with top-right selector.
- Use Prev/Today/Next navigation.
- Show grouped session rows.
- For a row, demonstrate:
  - Clickable name lane opens Find Taster with that child pre-searched.
  - Attendance toggle (Attendance/Attended/Missed).
  - Club Fees toggle.
  - BG toggle.
  - Badge toggle.
- Show Day Snapshot and Session Progress blocks.

## 7. Month View Demo

- Open Month view and switch location.
- Navigate month with Prev/Next.
- Show day boxes and initials inside each active day.
- Show Sunday visible but non-operating days visually inactive where relevant.
- Click a day cell to open day detail.
- Show Jump To panel (month/year quick navigation).

## 8. Add Taster Demo

- Open Add Taster.
- Pick location (Lockwood/Honley/Preschool) from top-right selector.
- Pick a class tile in the weekly grid.
- Show right-side add panel appears.
- Show taster date behavior:
  - Default suggestion is next upcoming class date.
  - Dropdown still allows a couple of prior weekly dates.
  - Weekly future options are available.
- Enter child name + optional notes and save.
- Confirm redirect to day view and record appears.

## 9. Record Leaver Demo

- Open Record Leaver.
- Pick class tile in weekly grid.
- Fill:
  - Child name,
  - Leave date,
  - Leave reason,
  - Notes,
  - Checklist toggles (inactive/BG/board).
- Save and confirm it appears in admin follow-up flow and stats impact.

## 10. Find Taster Demo

- Open Find Taster.
- Show search box with clear `×` button.
- Search by name, then clear and confirm all records return.
- Show filters:
  - Record type,
  - Programme,
  - Attendance,
  - BG,
  - Badge,
  - Unknown/known,
  - Date range slider.
- Explain filter behavior:
  - All filters default off.
  - With all off, all records are shown (recent-first).
  - Toggle filters on to narrow.
- Show Sort By options.
- Show row actions:
  - Edit,
  - Reschedule,
  - Remove.
- Show Taster Changelog page link.

## 11. Admin Tasks Demo

- Open Admin Tasks.
- Explain top totals:
  - Leavers this month,
  - Tasters to members this month.
- In “To Action” list, show:
  - Taster rows with Attendance/Contact/Reschedule/Fees/BG/Badge/No Space actions.
  - Leaver rows with leaver indicator + leaver-specific actions.
- Confirm section is internally scrollable and stable on screen.

## 12. Stats Demo

- Show top cards focused on recent period (not only lifetime totals).
- Explain:
  - Tasters to members,
  - Non-sign ups,
  - Leavers,
  - Net movement.
- Show line graph (tasters vs leavers) and totals.
- Show monthly table values.
- Show programme comparison bars.

## 13. Settings Demo

- Profile:
  - Update first name/last name/email.
- Admin Day Ownership:
  - Assign day/location ownership grid.
- Change Password:
  - Update current/new/confirm.
- Email Preferences:
  - Off/Weekly/Fortnightly/Monthly.
  - Send Day hidden unless Weekly/Fortnightly.
  - Monthly date selection appears for Monthly only.
- Remove Taster:
  - Search and remove selected record.
- Exports:
  - Export app-added tasters CSV.

## 14. Admin Menu Demo (Admin Account)

- Account Management:
  - Create account,
  - Edit account details/role/admin-day ownership,
  - Set new password for user,
  - Remove account (except owner safeguards).
- Weekly Email Reports:
  - Owner-only routing mode,
  - Test send to selected recipients.
- Cloud Preflight:
  - Environment/deploy readiness checks,
  - Backup/restore actions.
- Action Logs:
  - Demonstrate audit trail visibility.

## 15. Help / Suggestions Demo

- Open modal from sidebar.
- Submit a sample Help/Suggestion/Bug message.
- Explain this is the in-app feedback loop for quick improvements.

## 16. Mobile Demo Checklist

- Show mobile bottom taskbar:
  - Dashboard,
  - Today,
  - Month,
  - Admin menu (dropup).
- Open Admin dropup and show:
  - Stats,
  - Add Taster,
  - Record Leaver,
  - Find Taster,
  - Admin Tasks,
  - Settings,
  - Help / Suggestions,
  - Sign Out.
- Confirm no unusable overflow on core pages.
- Confirm key workflows complete on mobile:
  - Toggle attendance in day view,
  - Add a taster,
  - Search in Find Taster.

## 17. Closing Script (20-30 seconds)

- “That is the full daily workflow: add, action, track, and report.”
- “The system is optimized for fast staff actions, clear ownership, and audit visibility.”
- “Next, we can prioritize any extra automation or reporting the team wants.”

## 18. Presenter Tick-Off (Final)

- Security/login flow shown.
- All sidebar areas shown.
- Settings and Admin Menu both shown.
- Desktop and mobile both shown.
- End-to-end taster + leaver workflows shown.
- Find Taster search/filter/reschedule shown.
- Stats and dashboard reporting shown.
