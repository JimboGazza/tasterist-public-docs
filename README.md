# Tasterist

Hi, I am James Gardner, and I build bespoke class management systems for clubs and activity businesses.

Tasterist is a custom platform designed around real admin workflows: managing tasters, leavers, movers, hotleads, staff workload, tablet tools, and reporting in one place.
